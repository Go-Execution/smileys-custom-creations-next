# Smiley's Custom Creations — Next.js mockup

A Vercel-ready responsive mockup inspired by the supplied mobile references.

## Run locally

```powershell
npm install
npm run dev
```

## Production verification

```powershell
npm run build
```

The homepage includes responsive navigation, a mobile menu, newsletter modal and custom-order contact links. It is a visual mockup: product inventory and newsletter form submissions are not connected to a backend yet.
